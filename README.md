Были реферированы статьи издательства Газета.RU. Датасет статей был взят на Hugging Face : "IlyaGusev/gazeta"

Три из моделей - это модели с относительно небольшим количеством параметров. Все они были взяты на Hugging Face и  были специально дообучены для реферирования новостей издательства Газета.RU. Они решают исключительно задачу реферирования и только русских текстов. 

Остальные 7 моделей являются большими языковыми моделями, решающими большой перечень задач на разных языках. Доступ к ним были получен через API.
