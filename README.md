# Трансформеры для суммаризации текста

Этот проект посвящен исследованию и практическому применению моделей-трансформеров для задачи автоматического реферирования (суммаризации) текстов на русском языке.

В рамках работы был проведен сравнительный анализ различных языковых моделей, выбраны лучшие решения и реализованы сервисы для удобного использования.

## Структура проекта

Проект состоит из трех основных частей:

### 1. Сравнительный анализ (`comparison_and_analysis/`)

В этой директории находятся материалы исследования 10 различных языковых моделей:
- **3 специализированные модели** с Hugging Face (дообученные на датасете Gazeta.RU).
- **7 больших языковых моделей (LLM)**, доступных через API (GigaChat, YandexGPT, Llama, Mistral и др.).

**Ключевые результаты:**
- Проведено сравнение качества рефератов на основе 500 статей.
- Использованы метрики ROUGE и METEOR, а также визуальный анализ длин рефератов.
- Выделены лучшие модели по соотношению качества и скорости работы.

Подробности анализа, графики и выводы доступны в [README папки comparison_and_analysis](comparison_and_analysis/README.md).

### 2. API сервис (`fastapi/`)

Реализация REST API на базе фреймворка **FastAPI** для генерации суммаризаций.
- Позволяет отправлять текст и получать его краткое содержание.
- Поддерживает кэширование моделей и работу с GPU.
- Легко развертывается и конфигурируется.

Инструкция по запуску находится в [README папки fastapi](fastapi/README.md).

### 3. Телеграм-бот (`telegram-bot/`)

Удобный интерфейс для взаимодействия с сервисом суммаризации через Telegram.
- Пользователь отправляет текст боту и получает готовый реферат.
- Работает асинхронно, взаимодействуя с FastAPI сервисом.
- Поддерживает команды и меню.

Инструкция по настройке и запуску бота находится в [README папки telegram-bot](telegram-bot/README.md).
