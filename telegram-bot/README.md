# 🤖 Телеграм-бот для суммаризации текста

Удобный и быстрый бот для Telegram, который превращает длинные тексты в краткие и содержательные выжимки. Работает в связке с нашим FastAPI сервисом, используя мощь нейросетей для обработки информации.

## ✨ Возможности

*   **📝 Мгновенное реферирование**: Просто отправьте текст, и бот вернет его суть.
*   **🇷🇺 Полная поддержка русского языка**: Интерфейс и модели оптимизированы для работы с русскими текстами.
*   **⚡ Асинхронная работа**: Бот не "зависает" при обработке запросов благодаря асинхронной архитектуре.
*   **📊 Умная обработка**:
    *   Автоматическая проверка длины текста (минимум 50 символов).
    *   Корректная обрезка слишком длинных сообщений (до 4000 символов).
    *   Информативные сообщения о статусе обработки.
*   **📱 Удобное меню**: Встроенные команды `/start`, `/help` и `/info` для легкой навигации.

## 📂 Структура проекта

```bash
telegram-bot/
├── bot.py           # 🤖 Основной файл запуска бота
├── handlers.py      # 🎮 Обработчики команд и сообщений (логика бота)

└── .env.example     # 📝 Пример файла с переменными окружения
```

## 🚀 Установка и запуск

### Предварительные требования

1.  **Запущенный FastAPI сервис**: Бот обращается к нему для генерации рефератов. Убедитесь, что он работает (см. инструкцию в `../fastapi/README.md`).
2.  **Токен бота**: Получите его у [@BotFather](https://t.me/botfather), создав нового бота командой `/newbot`.

### 1. Установка зависимостей

```bash
cd telegram-bot
pip install -r requirements.txt
```

### 2. Настройка окружения

Создайте файл `.env` и укажите ваш токен:

```bash
cp .env.example .env
```

Откройте `.env` и отредактируйте:

```env
TELEGRAM_BOT_TOKEN=ваш_токен_от_BotFather
FASTAPI_URL=http://localhost:8000 # Адрес вашего FastAPI сервиса
```

### 3. Запуск бота

```bash
python bot.py
```

После запуска вы увидите сообщение в логах: `Starting bot...`. Теперь можно писать боту!

## 🎮 Как пользоваться

1.  Найдите своего бота в Telegram.
2.  Нажмите **Start** или отправьте команду `/start`.
3.  Отправьте любой длинный текст (статью, новость, пост).
4.  Подождите пару секунд...
5.  Готово! Бот пришлет краткое содержание и укажет модель, которая использовалась для генерации.

## 🛠 Команды

*   `/start` — Начать диалог и получить приветствие.
*   `/help` — Подробная инструкция по использованию и лимитам.
*   `/info` — Техническая информация о боте и используемой модели.

## ⚙️ Конфигурация (.env)

| Параметр | Описание |
|:---|:---|
| `TELEGRAM_BOT_TOKEN` | Токен вашего бота (обязательно) |
| `FASTAPI_URL` | URL API сервиса суммаризации (по умолчанию `http://localhost:8000`) |
| `FASTAPI_TIMEOUT` | Таймаут ожидания ответа от API (сек) |
| `MAX_MESSAGE_LENGTH` | Максимальная длина текста для обработки (символов) |

## 🐛 Решение проблем

*   **Бот не отвечает**: Проверьте, запущен ли скрипт `bot.py` и верен ли токен.
*   **Ошибка "Сервис недоступен"**: Убедитесь, что FastAPI сервис запущен и доступен по адресу, указанному в `FASTAPI_URL`.
*   **Текст не обрабатывается**: Проверьте длину текста — он должен быть длиннее 50 символов.
