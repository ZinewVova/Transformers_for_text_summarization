# 🚀 Сервис суммаризации текста на FastAPI

Мощный и гибкий REST API сервис для автоматического создания кратких содержаний (суммаризации) текстов на русском языке. Использует современные модели-трансформеры из экосистемы Hugging Face.

## ✨ Ключевые особенности

*   **🤖 Поддержка SOTA моделей**: Работает с любыми T5-based моделями (по умолчанию `IlyaGusev/rut5_base_sum_gazeta`).
*   **⚡ Высокая производительность**:
    *   Автоматическое использование **GPU (CUDA)** при наличии.
    *   Умное **кэширование моделей** в памяти для мгновенного доступа.
    *   Оптимизированная **очередь запросов** для стабильной работы под нагрузкой.
*   **🛠 Гибкая конфигурация**: Полная настройка через переменные окружения (Docker-friendly).
*   **🔍 Прозрачность**: Встроенная документация Swagger UI и ReDoc.

## 🚀 Быстрый старт

### 1. Установка зависимостей

Рекомендуется использовать виртуальное окружение:

```bash
python -m venv venv
source venv/bin/activate  # Linux/macOS
# venv\Scripts\activate   # Windows

pip install -r requirements.txt
```

### 2. Настройка окружения

Создайте файл `.env` на основе примера:

```bash
cp .env.example .env
```

Вы можете настроить параметры генерации, выбрать модель и указать параметры сервера.

### 3. Запуск сервера

```bash
# Запуск через Python
python main.py

# Или через Uvicorn (для разработки с авто-перезагрузкой)
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

Сервис будет доступен по адресу: `http://localhost:8000`

## 📚 Документация API

Интерактивная документация доступна сразу после запуска:

*   **Swagger UI**: [http://localhost:8000/docs](http://localhost:8000/docs) — удобный интерфейс для тестирования запросов.
*   **ReDoc**: [http://localhost:8000/redoc](http://localhost:8000/redoc) — красивая документация для разработчиков.

## 🔌 Примеры использования

### Python (requests)

```python
import requests

url = "http://localhost:8000/api/v1/summarize"
payload = {
    "text": "Вставьте сюда длинный текст статьи или новости...",
    "model_name": "IlyaGusev/rut5_base_sum_gazeta", # Опционально
    "max_source_tokens": 600 # Опционально
}

response = requests.post(url, json=payload)
print(response.json())
```

### cURL

```bash
curl -X 'POST' \
  'http://localhost:8000/api/v1/summarize' \
  -H 'Content-Type: application/json' \
  -d '{
  "text": "Вставьте сюда длинный текст...",
  "max_source_tokens": 600
}'
```

## ⚙️ Конфигурация (.env)

| Параметр | По умолчанию | Описание |
|:---|:---|:---|
| `HOST` | `0.0.0.0` | Адрес прослушивания сервера |
| `PORT` | `8000` | Порт сервера |
| `DEFAULT_MODEL` | `IlyaGusev/rut5_base_sum_gazeta` | Основная модель для суммаризации |
| `DEVICE` | `auto` | `cuda` (GPU) или `cpu`. Если не задано, определяется автоматически |
| `MAX_SOURCE_TOKENS` | `600` | Максимальная длина входного текста (в токенах) |
| `MAX_NEW_TOKENS` | `200` | Максимальная длина генерируемого реферата |

## 💡 Технические детали

*   **Семафор**: Для предотвращения переполнения памяти GPU (OOM) используется `asyncio.Semaphore(1)`, гарантирующий, что в каждый момент времени обрабатывается только один "тяжелый" запрос к модели.
*   **Кэширование**: При первом обращении модель загружается в память и остается там. Повторные запросы к той же модели выполняются мгновенно.
